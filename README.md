# Fallout2MigrationTool

A tool designed for migrating Fallout 2 data.

## Features
- Handles migration of Fallout 2 game assets and configuration.
- Built with C++ and CMake.

## Getting Started
To build the project, ensure you have CMake and a C++ compiler installed, then run the standard CMake build process.

For quick startup, you can use the `start.bat` script.
